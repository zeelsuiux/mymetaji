# MyMetaji PHP Conversion

Converted from the supplied HTML template to PHP.

## Shared components
- `includes/header.php` — common `<head>`, preloader, cursor, back-to-top and header/navigation.
- `includes/footer.php` — common footer, wrapper closing tags and JavaScript includes.

Edit these files once to update the header/footer across all pages.

## Pages
All original HTML pages are now `.php` pages. Internal `.html` links were updated to `.php`.

## CSS
The original CSS files under `assets/css/` were copied without modification.
